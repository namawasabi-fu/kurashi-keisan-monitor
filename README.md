# くらしの計算室・監視専用パッケージ

公開サイトを読み取るだけの週次検査です。Blogger、Search Console、Googleアカウントの認証情報は含みません。Node.js 22 の標準機能のみ使用します。

- ローカル検査: `node weekly_monitor.mjs`
- GitHub公開リポジトリのデフォルトブランチにこのフォルダの**中身だけ**を配置すると、ワークフローは毎週月曜02:17 UTCに実行します。
- Actionsの手動実行で初回動作を確認し、通知は本人が「失敗のみ」を選択してください。障害を自動修正しません。
- GitHubの公開リポジトリで標準ランナーは無料。ただし60日間リポジトリの活動がないと予定実行が無効になるため、完全放置はできません。
- 予定実行が止まると監視自身からは通知できません。6週間に1回ほど Actions の最終実行日とワークフローの有効状態を確認してください。停止時は手動で再有効化します。活動偽装の自動コミットは行いません。
- 失敗時の小さなJSONログだけを7日間アーティファクトに保存します。通信失敗は `monitor_transport_error` として記録し、サイトの故障とは断定しません。
- 2026-10-13 のGitHub共有ランナーでは、Bloggerへの一部リクエストがGoogleの制限ページへ転送され429になりました。この場合は数回の再試行後に `monitor_transport_error` で停止します。クラウドからの全件監視は現時点で安定稼働を確認できていません。アクセス制限の回避やCAPTCHA処理は行いません。
- 個人情報、認証トークン、Bloggerバックアップ、投稿本文をこのリポジトリへ入れないでください。

生成元は作業フォルダの `prepare_monitor_package_v13.mjs`。再生成後はローカル検査を実行してください。
